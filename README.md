# Little Reminder — Phase 1 Animation Build

This build keeps the working v2.1 reminder scheduler/background behavior and upgrades the water companion entrance animation.

## Phase 1
- water ripple/splash entrance
- small rising droplets
- mermaid rises into position with a soft bounce
- glass rises after the character
- speech bubble pops in
- reminder card slides in last
- gentle idle floating after the entrance

## Test
Run the existing project normally. Schedule a reminder a few minutes ahead, close the settings window, and let the tray app trigger it. The animation should play automatically.
